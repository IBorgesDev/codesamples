# Roblox backend systems

Four independent projects, each in its own folder with its own code and README.

| Project | What it is |
|---|---|
| [trades](trades/) | Trades and gifts between players that never lose or duplicate an item |
| [live-events](live-events/) | A global goal or vote that every server adds to and shows within seconds |
| [analytics](analytics/) | Game events from Roblox servers into ClickHouse, each stored exactly once |
| [dashboard](dashboard/) | A live web dashboard over the analytics and the live events |
