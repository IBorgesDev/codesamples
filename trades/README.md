# Trades

Code for trading items and coins between players in a Roblox game, on the same server or across
servers, plus gifts to players who are offline.

It solves the hard part of trading: no item or coin is ever lost or duplicated, even when a server
crashes in the middle of a trade, and a modified client cannot cheat or flood through the remotes.

## Run

```bash
mise install
mise run install
mise run serve
```

Connect the Rojo plugin in Studio (port 34875) and enable Studio Access to API Services. Every
playtest runs the tests first.
